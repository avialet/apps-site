Des apps pour Mac, libres et gratuites.

Je conçois de petites apps natives pour le quotidien et je les partage ici, code source ouvert sous licence MIT. Chaque app se télécharge librement et se lit sur GitHub.

  • Pico Le gestionnaire de tâches qui comprend vos phrases. pico.vialet.app
  • Allège Allège vos images sans les envoyer nulle part. allege.vialet.app
  • Pince Gardez plusieurs copies sous la main. pince.vialet.app
  • Brouillon Le bloc-notes qui comprend ce que vous y collez. brouillon.vialet.app

Chaque app vit sur son propre site, avec son code et ses versions sur GitHub. Les sites ne posent aucun cookie et ne mesurent rien.
